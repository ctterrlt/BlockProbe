## App icon

Place the source artwork at `src/assets/icon.png`:

- 1024 x 1024 px PNG with a transparent background.
- Artwork fills the canvas; do not add margins.
- Flet generates the macOS `.icns`, Android adaptive icons, iOS icons and web icons from this file; `icon_windows.ico` is provided as the Windows override.
- The icon background colour is set in `pyproject.toml` (`[tool.flet] icon_background`).

Optional per-platform overrides, also in `src/assets/`: `icon_ios.png`, `icon_macos.png`, `icon_android.png`, `icon_web.png`, `icon_windows.ico`, `icon_linux.png`.

## Splash screen

- `src/assets/splash.png` for light mode and an optional `src/assets/splash_dark.png` for dark mode.
- Square PNG with a transparent background.
- Background colours are configured in `pyproject.toml` under `[tool.flet.splash]`.

The application icon is the supplied BlockProbe artwork at `src/assets/icon.png` (1024 x 1024 px RGBA with transparent corners). A multi-size Windows override is provided at `src/assets/icon_windows.ico`; the other platform icons are generated by Flet from the PNG. The splash screen at `src/assets/splash.png` remains a neutral placeholder until final splash artwork is supplied; replace it before the first public release and keep the same file name and dimensions.
